# Trivia Game in C++

A text-based Trivia Game built in C++ that features multiple difficulty levels, a scoring system, and a leaderboard.

## Features

- **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard.
- **Dynamic Questions:** A wide range of questions covering various topics (Mathematics, Geography, History, Language, etc.).
- **Lives System:** You start with 2 lives. Every incorrect answer costs a life.
- **Leaderboard:** Track your high scores and compete with others.
- **Interactive UI:** Simple and clean console interface.

## How to Play

1. **Compile the Code:**
   Use a C++ compiler like `g++` to compile `Trivia.cpp`.
   ```bash
   g++ Trivia.cpp -o Trivia
   ```
2. **Run the Executable:**
   ```bash
   ./Trivia
   ```
3. **Follow the Prompts:** Enter the number corresponding to your choice to navigate the menus and answer questions.

## Project Structure

- `Trivia.cpp`: The main source code containing the game logic, questions, and UI.
